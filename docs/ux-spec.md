## 1. 导航与布局

### 全局布局

- **顶栏**（所有页面）：左侧返回箭头 / 首页图标，中间页面标题，右侧默认无操作（MVP 简洁优先）。**首页例外**：右侧放置小朋友管理入口图标（👤），见 §2.1。
- **底部导航栏**（3 项）：🏠 批改 · 📋 历史 · ⭐ 错题集
- **无侧边栏**：移动端优先，所有导航通过底部 tab 完成
- **内容区**：填充剩余视口高度，页面级滚动

### 响应式策略

| 断点    | 宽度       | 布局                                      |
| ------- | ---------- | ----------------------------------------- |
| Mobile  | < 768px    | 单列，底部导航，全屏面板（375px 设计基准） |
| Desktop | ≥ 768px    | 最大宽度 480px 居中，底部导航保持在底部     |

> MVP 不追求桌面端复杂布局——桌面端就是"手机界面居中显示"。

### 导航结构

```
批改（首页）  ←── 默认入口
  ├── 拍照上传 → 批改中 → 批改结果 → (人工修正)
  └── 小朋友管理（入口在顶栏）

历史
  ├── 历史列表 → 历史详情 → (人工修正)

错题集
  ├── 错题筛选列表 → 生成错题试卷
```

## 2. 屏幕规格

### 2.1 首页 · 批改上传（实现 F-01, F-02, F-04）

**路由：** `/`

**布局（从上到下）：**

1. **顶栏**：标题"AI 作业批改"，右侧小朋友管理图标（👤）
2. **当前选择区**：
   - 小朋友名字（下拉选择器，列出当前家长的小朋友列表）
   - 学科（分段控件：英语 | 数学）
3. **拍照上传区**（主交互区，占页面中央 60% 区域）：
   - 虚线边框的大矩形区域（`border-2 border-dashed`）
   - 图标：📸 相机 icon + 文字"拍照上传试卷"
   - 说明文字："支持英语 · 数学 · 打印体 + 手写"
   - **点击行为**：弹出底部 ActionSheet
     - "📷 拍照"（调起后置摄像头，`capture="environment"`）
     - "🖼️ 从相册选择"
4. **已选图片预览**（上传前）：
   - 缩略图展示已选图片（压缩后预览）
   - 右上角 ✕ 可移除，重新选择
5. **提交按钮**："开始批改"（主色按钮，全宽，已选图片后激活）

**交互：**
- 未选图片时"开始批改"按钮置灰不可点击
- 选择图片后自动压缩（前端静默处理，无用户感知）
- 点击"开始批改"→ POST /api/submissions → 跳转到批改中页面

**状态：**
- **首次使用**：小朋友列表为空 → 引导"请先添加小朋友"，点击跳转小朋友管理
- **选择图片后**：显示压缩后预览缩略图
- **网络错误**：Toast"上传失败，请重试"，按钮恢复可点击

### 2.2 小朋友管理页（实现 F-04, F-08）

**路由：** `/children`

**布局：**

1. **顶栏**：标题"小朋友管理"，左侧返回箭头
2. **列表区**：每个小朋友一行卡片
   - 名字（可编辑，点击进入编辑模式或弹出编辑框）
   - 已批改次数统计（如"已批改 23 次"）
   - 右侧删除按钮（🗑️，点击弹出确认对话框）
3. **底部**："+ 添加小朋友"按钮

**交互：**
- 添加：弹出输入框，填写名字后确认 → POST /api/children
- 编辑：点击名字 → 输入框变为可编辑 → 确认后 PUT
- 删除：点击 🗑️ → 确认对话框"删除 XXX？删除后历史试卷保留"
- 默认值：预置"小朋友1"、"小朋友2"

**状态：**
- **空列表**：不应出现（首次使用有默认值），但保留空状态文案
- **操作失败**：Toast 错误信息

### 2.3 批改中（等待结果，实现 F-01 异步流程）

**路由：** `/submissions/:id/processing`

**布局：**

1. **顶栏**：标题"批改中…"，无返回按钮
2. **中央动画区**：
   - 大号加载动画（旋转的 ✏️ 或脉冲圈）
   - 文字"AI 正在批改…"（轮播文案）：
     - "🔍 识别题目中…"
     - "✏️ 批改答案中…"
     - "📝 生成解题思路中…"
   - 进度条（不确定模式，持续滚动）
3. **预计时间提示**："通常需要 5-15 秒"
4. **取消按钮**（可选）："取消"——但后台任务不中断，仅返回首页

**交互：**
- 前端每 2 秒轮询 `GET /api/submissions/{id}`
- `status == "completed"` → 自动跳转批改结果页
- `status == "failed"` → 显示错误信息 + 重试按钮
- 30 秒超时 → 显示"批改超时，请重试"

**状态：**
- **轮询中**：正常显示动画
- **失败**：红色提示"批改失败：{detail}"，下方"重新批改"和"返回首页"两个按钮
- **超时**：黄色提示"批改时间较长，请稍候或重试"

### 2.4 批改结果页（实现 F-03, F-02 AC-07 人工修正）

**路由：** `/submissions/:id/result`

**布局：**

1. **顶栏**：标题"批改结果"，左侧返回首页，右侧分享/下载（可选）
2. **得分概览卡片**（顶部）：
   - 大号分数显示"✅ 8/10"（正确数/总题数，绿色）
   - 或"❌ 3/10"（错误较多时红色强调）
   - 学科标签 + 提交时间（相对时间："5 分钟前"）
3. **批改后图片**（可双指缩放查看）：
   - 全宽展示 annotated_image
   - 点击进入全屏预览模式（lightbox），双指缩放
4. **逐题明细列表**（可折叠展开）：
   - 每道题一行：题号、题型标签、✓ 或 ？+ 解题思路（仅错题）
   - 错题行有红色左边框强调
   - 点击错题行：展开解题思路完整文字
5. **人工修正开关**：
   - 每道题右侧有切换开关（对/错）
   - 切换后立即 PATCH，成功后提示"已更新"
   - 切换后得分概览实时更新

**状态：**
- **加载中**：骨架屏（得分卡片 + 图片占位 + 3 行明细占位）
- **图片加载失败**：占位图 + "图片加载失败" + 重试
- **修正保存失败**：Toast + 开关回弹到原值

### 2.5 历史列表页（实现 F-05）

**路由：** `/history`

**布局：**

1. **顶栏**：标题"批改历史"
2. **筛选栏**（顶部固定）：
   - 小朋友下拉（默认：全部）
   - 学科下拉（默认：全部）
3. **列表区**（无限滚动或加载更多）：
   - 每条记录卡片：
     - 左侧：试卷缩略图（64×64px，圆角）
     - 中间：小朋友名字 + 学科标签 + 得分（"8/10 ✅"）
     - 右侧：相对时间（"5 分钟前" → "昨天" → "7月20日"）
   - 点击卡片 → 跳转历史详情页
4. **分页**：滚动到底部自动加载更多（"加载更多…" 按钮兜底）

**状态：**
- **加载中**：骨架卡片 × 5
- **空列表**："还没有批改记录。去批改一张试卷吧！" + "去批改"按钮（跳转首页）
- **加载失败**：错误提示 + 重试按钮
- **加载完毕**：底部显示"—— 已显示全部记录 ——"

### 2.6 历史详情页（实现 F-05, F-03 人工修正）

**路由：** `/submissions/:id`

**布局（同批改结果页，额外增加）：**

1. **顶栏**：标题"批改详情"，左侧返回
2. **图片对比视图**（可切换标签）：
   - 标签栏：原图 | 批改后
   - 默认显示"批改后"
   - 切换时图片淡入切换，不跳变
3. **修改时间线**（如有）：
   - 显示人工修正记录："7月20日 21:30 将第3题由 ❌ 改为 ✅"

**状态：** 同 2.4 批改结果页。

### 2.7 错题集页（实现 F-06）

**路由：** `/errors`

**布局：**

1. **顶栏**：标题"错题集"
2. **筛选栏**（顶部固定）：
   - 小朋友下拉
   - 学科下拉
   - 题型下拉（全部 / 选择题 / 填空题 / …）
   - 时间范围（"最近一周" / "最近一月" / "全部" / 自定义日期范围）
3. **统计摘要**（筛选栏下方）：
   - "共 X 道错题"
4. **错题列表**：
   - 每道错题卡片：
     - 题目截图（从原图裁剪的区域）——全宽展示
     - 题号 + 题型标签 + 所属试卷时间
     - 解题思路文字（折叠，点击展开）
   - 点击 → 跳转到对应提交的历史详情
5. **底部操作栏**（固定）：
   - "生成错题试卷"按钮（全宽，主色）
   - 携带当前筛选条件跳转错题试卷生成页

**状态：**
- **加载中**：骨架卡片 × 3
- **空结果**："🎉 没有符合条件的错题！"（筛选后无结果）或"还没有错题。去批改试卷吧！"（从未有过错题）
- **加载失败**：错误提示 + 重试

### 2.8 错题试卷生成页（实现 F-07）

**路由：** `/errors/generate`

**布局：**

1. **顶栏**：标题"生成错题试卷"，左侧返回
2. **参数设置区**：
   - 小朋友（继承自错题集筛选，可改）
   - 学科（继承自错题集筛选，可改）
   - 题型（多选：全选 / 选择题 / 填空题 / …）
   - 时间范围（继承）
   - 题目数量滑块（1-50，默认 10）
3. **预览区**（生成后）：
   - 生成的错题试卷图片，全宽展示，可缩放
4. **底部操作**：
   - "生成试卷"按钮（主色，全宽）→ POST /api/error-collections/generate
   - 生成后 → "保存图片" / "打印"（调用浏览器打印）

**状态：**
- **生成前**：参数设置区可见，预览区显示占位"调整参数后点击生成"
- **生成中**：按钮显示 loading，"正在生成错题试卷…"
- **生成完成**：预览区展示图片，底部按钮变为"重新生成" + "保存/打印"
- **生成失败**：Toast 错误信息

## 3. 交互模式

### 照片上传

- 点击上传区 → 底部 ActionSheet 弹出（从屏幕底部滑入，约 200ms 动画）
- 选择"拍照" → 浏览器 `<input capture="environment">` 调起原生相机
- 选择"从相册" → 浏览器文件选择器
- 图片压缩在 Web Worker 中执行（不阻塞 UI），压缩完成后预览区显示缩略图

### 提交反馈

- **批改提交**：按钮显示 loading spinner + "正在上传…"，期间禁用按钮
- **轮询**：批改中页面每 2 秒轮询，状态变更后自动跳转，无用户操作
- **人工修正**：开关切换后立即保存，失败时回弹

### 加载状态

- **页面首屏**：骨架屏（Skeleton），匹配内容布局，脉冲动画
- **操作进行中**：按钮内 spinner 替换文字，按钮禁用
- **列表加载更多**：底部"加载更多…"文字 + spinner

### 错误状态

| 错误 | 展示方式 | 恢复操作 |
|------|---------|---------|
| 网络请求失败 | 底部 Toast（红色），3 秒后自动消失 | 自动重试 1 次；手动点重试按钮 |
| 图片压缩失败 | Toast "图片处理失败，请重试" | 重新选择图片 |
| 批改失败 | 批改中页面显示错误 + 详情 | "重新批改" / "返回首页" |
| 批改超时（30s）| 黄色提示"批改超时" | "继续等待" / "重试" |
| 404 | 全页"页面不存在" + 返回首页 |
| 500 | Toast "服务器错误，请稍后重试" |

### 空状态

每条空状态都有明确下一步操作，不含糊：

| 页面 | 空状态文案 | 操作 |
|------|-----------|------|
| 历史列表 | "还没有批改记录。去批改一张试卷吧！" | "去批改"按钮 |
| 错题集（无错题）| "🎉 还没有错题。继续保持！" | "去批改"按钮 |
| 错题集（筛选后）| "没有符合条件的错题" | "清除筛选"按钮 |
| 小朋友列表 | "请先添加小朋友" | "添加"按钮（引导式）|

## 4. 辅助功能

**目标：** MVP 阶段做到基本可用，不追求 WCAG 正式合规（家庭自用场景）。

**基本要求：**

- 所有按钮和链接可通过 `Tab` 键聚焦，`Enter` 激活
- 图片上传区有清晰的 `aria-label`
- 批改结果图片有 `alt` 描述
- 得分信息不以颜色为唯一传达方式（同时显示数字）
- Toast 消息使用 `role="alert"` 以便屏幕阅读器感知
- 触控目标 ≥ 44×44px（Tailwind `min-h-11 min-w-11`）
