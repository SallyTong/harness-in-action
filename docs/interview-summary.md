# AI作业批改工具 -- 项目访谈摘要

<!-- 本文档是结构化访谈的输出，记录了产品愿景和技术决策，是后续 PRD、架构文档的基础。 -->

## 产品愿景

AI 驱动的作业批改工具，帮助家长高效检查孩子的试卷和作业。用户拍照上传试卷，AI 自动在原图上标注批改结果（打勾、打问号、写解题思路），返回一张批改后的图片。同时试卷存入后端系统，支持错题统计和错题集试卷生成。解决家长每天检查作业耗时长、准确率不稳定的痛点。

MVP 阶段覆盖**英语**和**数学**两门学科，支持打印体试卷 + 手写作答的混合识别。未来扩展语文作文、报听写等多学科功能。

## 目标用户画像

- **主要用户**：家长（检查孩子作业）和学生（做完后自检）
- **使用场景**：小学阶段（当前为五年级和二年级），每天检查试卷、作业、听写
- **规模**：先小范围试用（家庭成员），后续对外开放
- **账号模型**：一个小朋友一个账号，MVP 阶段不设注册/登录系统，先快速跑通功能
- **协作**：同一小朋友的试卷支持多个家长查看（多人协作）

## 核心体验

用户用手机打开 Web 页面 → 拍照上传试卷（前端自动压缩） → 几秒后看到 AI 在原图上标注的批改结果（正确处打勾、错误处打问号、错题旁写解题思路） → 结果即时反馈。历史试卷可回溯浏览，错题自动归入错题集，支持按时间范围和题型筛选，一键生成错题试卷。

## 技术栈决策

| 层级       | 选型                                                     |
|------------|----------------------------------------------------------|
| 大模型 API | 智谱 GLM-4V-Flash（免费版先行验证，效果不够再切 GLM-4V-Plus） |
| 前端       | Web 页面（移动端优先，拍照上传为主场景），后续无缝迁移至小程序/移动 App |
| 后端       | Python，FastAPI 框架                                     |
| 数据库     | MySQL                                                   |
| 图片存储   | 本地文件系统（MVP），后续迁移至阿里云 OSS                   |
| 部署       | Docker 容器化，MVP 阶段本地部署（IP+端口访问），后续上阿里云 |
| 图片处理   | Web 端压缩后再上传（最长边 2048px，JPEG 质量 80%），兼顾清晰度和传输速度 |

### 核心处理流程

```
拍照 → Web端压缩 → 上传 → GLM-4V 多模态识别+批改 → 标注回原图 → 返回批改后图片 → 存储
```

采用多模态大模型直接理解图片内容，无需独立 OCR 中间步骤，对手写体和打印体混合场景的识别优于传统 OCR。

## 不可协商的约束

- GLM-4V API 月度预算不超过 50 元（日均约 10 次调用）
- MVP 一周内交付可试用版本
- 图片存储本地文件系统，不依赖云服务
- 无域名/HTTPS，IP+端口直接访问
- 单人开发（资深程序员 + AI 辅助）
- Web 页面移动端优先设计

## MVP 不做的事项

- 用户注册/登录系统（一个小朋友一个账号，简单区分即可）
- 图片脱敏处理（自用阶段不需要，对外开放后再加）
- 微信小程序 / 移动 App（先用 Web，后续无缝迁移）
- 云端图片存储（先用本地，后续迁移）
- 家长端 vs 学生端角色区分
- 通知/提醒功能
- 批改结果导出 PDF
- 语文作文、报听写等其他学科（MVP 只做英语和数学）
- Gantt 图表 / 学习趋势分析等复杂数据报表
